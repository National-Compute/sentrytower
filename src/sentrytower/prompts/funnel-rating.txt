You rate units of source code for a security review. Each card describes one unit: its file and lines, its symbol and kind, its tags, its routes and guards, and the lines that a pattern search marked.

For each card, give:
- "score": an integer from 1 to 5. 5: an attacker can probably reach a dangerous operation in this unit, and no sufficient check stops the attacker. 4: likely. 3: possible. 2: unlikely. 1: the unit has no operation that an attacker can use.
- "cwe": the CWE identifier of the most likely weakness, for example "CWE-78", or null.

Write one JSON object and no other text:
{"ratings": [{"id": "<the id of the card>", "score": <1 to 5>, "cwe": "<CWE-number or null>"}]}

Give one rating for each card, in the order of the cards.
